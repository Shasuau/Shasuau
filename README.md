## 📌 About Me
- I'm a Computer Science graduate based in the Sydney area. I currently work in a graduate role, rotating through penetration testing and security engineering.
- Alongside my work in cyber I like to build my own personal tooling. A few of those projects are hosted here, and the rest run on my private home server. The automations I'm happiest with are a spending tracker built off the Apple Wallet notifications on my phone, and a tax bot that takes the receipts out of my emails, adds them to a database and sends them back to me at EOFY. I also run two public sites: my portfolio, which is a bit out of date now but still looks cool, and my writeups site, which covers a few of my early HTB boxes.


## 🧠 My Focus Areas
- Penetration testing: enumeration, exploitation and post-exploitation, at work and in HackTheBox labs.
- Security engineering: the defensive and infrastructure side of the rotation.
- Personal tooling: Python automation, GitHub Actions, and a home server I keep finding new jobs for.
